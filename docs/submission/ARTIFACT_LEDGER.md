## 持续记录规则

1. 每个工单完成后保存测试命令、结果摘要和 Git 提交号。
2. 关键终端步骤保留文本输出，并补充无敏感信息的截图。
3. 每次模型或性能实验保存原始 JSON、配置快照、环境参数和汇总表。
4. 新增 AI 生成代码或文档时，当次更新 `docs/ai_usage/AI_USAGE.md`。
5. 所有提交材料不得包含账号、密钥、私钥或个人敏感信息。
